Architecture & privacy
Security boundaries
Identity artefacts often contain personal information and live bearer credentials. The public application is deliberately static and local-first.

      

        
Runtime boundary
  • No backend, analytics or telemetry.
  • connect-src 'none'; no fetch/XHR/WebSocket/EventSource path.
  • No token/claim persistence to localStorage, sessionStorage or IndexedDB.
  • Raw tokens are excluded from diagnostic reports.
  • jku, x5u, jwks_uri, federation endpoints and SAML URLs are displayed only.

        
XML signature verification
  • xmldsigjs 2.8.8 is vendored locally under public/assets/js/external/.
  • Package/runtime versions are pinned in package.json; the build records bundled versions in a SHA-384 vendor manifest.
  • The local script is loaded with an SRI integrity attribute.
  • CI independently recalculates the bundle hash and compares it with both the manifest and HTML SRI value.
  • Valid XMLDSig does not imply trusted signing certificate or valid SAML profile.

      

      
Roadmap foundation
Implemented surfaces
v0.1JWT / JOSE inspection, time/issuer/audience checks, local JWK/JWKS signature verification.
v0.2OIDC ID Token nonce/azp/auth_time/at_hash/c_hash analysis, RFC 9068 JWT access tokens, discovery/JWKS security guidance, scopes/roles/entitlements.
v0.3SAML Response/Assertion, SubjectConfirmation, Conditions/AudienceRestriction, NameID, AuthnContext, attributes, signature coverage and local XMLDSig verification.
v0.4JWT ↔ SAML ↔ WS-Fed semantic claim mapping, custom aliases, migration summaries and downloadable migration reports.
v0.5WS-Federation / WS-Trust envelope, AppliesTo/lifetime analysis and embedded SAML 2.0 or SAML 1.x enterprise assertions.
v0.6OIDC/SAML/JWKS/OpenID Federation inspection, configuration diffing, issuer migration and signing-key/certificate rotation analysis.

      
Alpha scope: these are implementation foundations, not claims of complete protocol conformance. See ROADMAP.md and SECURITY.md for hardening work required before stable 1.0.
